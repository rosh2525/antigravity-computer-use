# Security

Computer Use can see and operate apps on your Mac, so security reports matter here.

Please **do not** open a public issue for a vulnerability. Report it privately through
[GitHub Security Advisories](https://github.com/rosh2525/antigravity-computer-use/security/advisories/new).

Things that count: ways to drive the helper without the user's consent (bypassing app approval, the
Esc stop, or the lock-screen check), other local processes talking to the helper's socket, the helper
leaking screenshots or clipboard contents, or prompt-injection paths that the skill/rules should guard.
